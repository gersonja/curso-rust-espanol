# 🦀 Estructuras Fijas en Memoria: Tuplas, Arrays y Slices

Gestión de memoria contigua en el Stack con tipos compuestos: tuplas multidimensionales, arrays fijos [T; N] sin heap overhead, y slices (&[T]) como vistas no propietarias (puntero + longitud).

---

## 🚀 Cómo Ejecutar este Proyecto

Ubícate en esta carpeta desde tu terminal:

```bash
# 1. Verificar la sintaxis y tipos
cargo check

# 2. Compilar y ejecutar el proyecto
cargo run

# 3. Ejecutar las pruebas unitarias
cargo test

# 4. Auditoría estricta de buenas prácticas con Clippy
cargo clippy --all-targets -- -D warnings
```

---

## 💡 Conceptos Clave en el Código
El archivo [`src/main.rs`](src/main.rs) contiene el código completamente funcional y documentado con comentarios técnicos de arquitectura, explicando qué ocurre en el Stack y Heap en cada instrucción.
