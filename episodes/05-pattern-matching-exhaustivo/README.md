# 🦀 Pattern Matching Exhaustivo con match y Enums

El sistema de bifurcación más potente de los lenguajes modernos: garantía de exhaustividad en tiempo de compilación, deconstrucción de Enums ricos con datos asociados, match guards y azúcar sintáctico if let.

---

## 🚀 Cómo Ejecutar este Proyecto

Ubícate en esta carpeta desde tu terminal:

```bash
# 1. Verificar la sintaxis y tipos
cargo check

# 2. Compilar y ejecutar el proyecto
cargo run

# 3. Ejecutar las pruebas unitarias
cargo test

# 4. Auditoría estricta de buenas prácticas con Clippy
cargo clippy --all-targets -- -D warnings
```
