# 🦀 Control de Flujo y Expresiones en Rust

Diferencia fundamental entre sentencias y expresiones, retornos implícitos sin semicolon, bloques de código que evalúan a un valor, if como expresión y bucles (loop con valor, while, for en rangos).

---

## 🚀 Cómo Ejecutar este Proyecto

Ubícate en esta carpeta desde tu terminal:

```bash
# 1. Verificar la sintaxis y tipos
cargo check

# 2. Compilar y ejecutar el proyecto
cargo run

# 3. Ejecutar las pruebas unitarias
cargo test

# 4. Auditoría estricta de buenas prácticas con Clippy
cargo clippy --all-targets -- -D warnings
```
